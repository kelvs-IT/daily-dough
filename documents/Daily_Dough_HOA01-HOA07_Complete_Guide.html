Project Title: Daily Dough: An On-Demand E-Commerce Platform for Donut Ordering and Delivery

1. Project Overview & Architecture

Daily Dough is an on-demand mobile-commerce (M-Commerce) platform designed for boutique bakery storefronts specializing in artisanal donuts and specialty coffee. The platform bridges customer ordering convenience with streamlined administrative management through two synchronized client applications connected to a single cloud database:

  1. Customer Mobile Application: Developed with Flutter & Dart, supporting registration, catalog browsing, isolated carts, 3-step checkout, and real-time order tracking.
  2. Admin Web Application: Developed with HTML5, CSS3, and JavaScript, providing live sales analytics, product catalog CRUD, customer monitoring, and order status lifecycle updates.
Architectural Choice: Cloud Firestore vs. Firebase Realtime Database
While the ITE 7 Module describes Cloud Firestore, Daily Dough utilizes Firebase Realtime Database (RTDB). Both are official Google Firebase NoSQL products. Realtime Database was selected because its flat JSON tree structure delivers ultra-low latency updates ideal for on-demand food delivery order status tracking.
