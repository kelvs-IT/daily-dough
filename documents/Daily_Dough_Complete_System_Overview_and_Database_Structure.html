An On-Demand E-Commerce Platform for Donut Ordering and Delivery

Backend Database: Google Firebase Realtime Database (RTDB)
Documentation Release: Version 2.0 (Official Capstone & Defense Guide)

1. Executive Summary & Project Description

Daily Dough is an integrated mobile and web e-commerce solution engineered to digitize the ordering, culinary preparation, delivery tracking, and administrative orchestration of fresh handcrafted donuts, specialty pastries, and premium brewed coffee beverages. The platform pairs a high-performance native Flutter Android client with a lightweight responsive Web Admin Dashboard, powered by Google Firebase Realtime Database via direct REST APIs over HTTPS.

2. System Architecture & Component Design

The system follows a Serverless Client-Cloud Decoupled Architecture. Both client applications communicate directly with Google Firebase services without requiring an intermediate custom server.

6. Academic Analysis: Cloud Firestore vs. Realtime Database

Key Defense Talking Point for ITE 7 Curriculum
The ITE 7 academic module references Cloud Firestore collections and documents. However, Daily Dough was engineered using Firebase Realtime Database (RTDB). Both products are official Google Firebase NoSQL solutions. RTDB was selected because its flat JSON tree structure provides sub-second reactive updates for active cart calculations and on-demand order fulfillment tracking, while minimizing client APK size (~57.1 MB) by avoiding heavy native client SDK dependencies.

7. Conclusion

Daily Dough represents a fully realized, defensible, production-grade e-commerce application. By seamlessly uniting a Flutter mobile client and an HTML5/JavaScript administrative portal through Google Firebase Realtime Database, it exemplifies best practices in reactive state management, asynchronous REST communication, and transactional data integrity.
