# Document-Generation Workflow Rule

All documents created for the Daily Dough project must automatically be saved inside the project document folder:
`C:\Users\benzy\.gemini\antigravity-ide\scratch\daily-dough\documents/`
(Linked path: `C:\Users\benzy\.gemini\antigravity-ide\scratch\daily-dough\document/`)

### Rules
1. Save all generated documentation (technical, system, reports, manuals, meeting notes, etc.) directly in `C:\Users\benzy\.gemini\antigravity-ide\scratch\daily-dough\documents/`.
2. Never save documents in the project root or Downloads folder unless explicitly requested.
3. Do not create another `document` folder.
4. Do not move, overwrite, or delete existing documents without explicit permission.
5. Do not save source code, images, logos, or application assets in the document folder.
6. Support requested formats: PDF, DOCX, TXT, XLSX, PPTX, MD.
7. Ask if format or filename is unclear.
8. If the folder cannot be accessed, report the issue immediately.
9. Always provide the full path and clickable link to the user upon creation.
